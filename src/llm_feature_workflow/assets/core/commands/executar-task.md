# Implementa uma task candidata a review

Implemente uma única task a partir do `TASK_BASE_SHA` fornecido.

Não faça commit, não marque checkbox e não altere versão. Leia task, PRD, Tech Spec, profile-context e rules apontadas. Se a especificação estiver materialmente errada, retorne `SPEC_GAP`; não improvise.

Implemente escopo e evidências, execute os gates aplicáveis de `.workflow/generated/profile-context.md` e retorne `CANDIDATA_A_REVIEW`, `FALHOU` ou `SPEC_GAP` com arquivos e resultados.
