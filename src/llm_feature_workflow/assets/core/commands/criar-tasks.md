# Decompõe planejamento aprovado em entregáveis rastreáveis

Não implemente código. Mostre primeiro uma matriz high-level com entregável, RF/NFR, DEC/TEST, dependências e paralelismo; aguarde aprovação humana.

Prefira slices verticais observáveis. Cada task referencia requisitos, decisões, riscos, testes, regras e plugins aplicáveis. Evidência é proporcional ao comportamento; não force todos os níveis de teste.

Gere `tasks.md` e `[num]_task.md`, marque o plano como `DRAFT` e instrua executar `validar-planejamento.md`.
